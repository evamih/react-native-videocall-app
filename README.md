# react-native-videocall-app
Video &amp; Audio Calling App built with Stream SDK in React Native

A mobile app i created that uses the Stream Video-Audio SDK to let users join classic meeting rooms that have all the necessary functionalities for enjoying a social, educational or professional videoconference. The meeting rooms also have an associated chat and can hold up to 20 people. This application uses a custom made API that handles the POST requests to register and log users in. You can check the repo out at https://github.com/evamih/am-api-stream.
